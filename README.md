# Glynac Wealth Management & Compliance Platform

An enterprise-grade frontend platform built for wealth management and compliance workflows.

This project was developed as part of the Glynac Frontend Engineering Assignment using Next.js, TypeScript, and Tailwind CSS.

## 🚀 Project Overview

The platform brings together four major frontend modules into a unified compliance workspace:

- Virtual Data Room
- AI Compliance Chat
- Enterprise Admin Panel
- Interactive Visual Tree Editor

The application uses mock data and local frontend state to demonstrate realistic enterprise workflows without requiring a production backend.

---

## ✨ Features

### 1. Virtual Data Room

A secure document management interface designed for compliance and wealth-management workflows.

Features include:

- Document and folder navigation
- Search, filtering, and sorting
- Folder creation, renaming, and deletion
- File upload with drag-and-drop support
- Multiple file selection
- Document preview
- PDF, JSON, image, Markdown, and text previews
- Compliance flags and security tags
- Permission management
- Audit log
- Document download functionality
- Responsive enterprise UI
